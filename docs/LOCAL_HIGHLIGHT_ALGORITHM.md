# 本地高亮算法

## 产品结论

落点的浏览器扩展使用独立本地算法，不请求第三方阅读高亮服务。用户触发后，正文抽取、候选评分、落点选择、DOM 注入和完整撤销全部在当前页面完成。

```text
正文文本节点
  → 中英文词与复合短语候选
  → 信息量、关系词、数字与重复概念评分
  → 从当前阅读光标选最早的强候选
  → 保留至少一个字的视觉间隔
  → 原页笔刷高亮
```

## 当前质量基线

- 9 个真实段落、53 个人工标注短语中，完整候选召回率为 90.6%。
- 已知错误词边界率为 0。
- 典型中文段落的高亮覆盖率稳定在 25%–50% 之间。
- 候选和选择结果确定；同一输入不受网络或模型波动影响。

## 安全约束

- 只处理高置信度正文块，排除导航、按钮、页脚、代码和隐藏内容。
- 避开原页已有的链接、粗体、斜体、`mark` 和明显异色强调。
- 不改变页面纯文本、链接地址和 URL。
- 再次触发时移除所有插件节点与样式。
- 不记录正文或页面 URL，扩展不申请持久站点权限。

## 未完成的验证

当前自动化和真实浏览器验收证明实现安全、可撤销且布局稳定，但不证明阅读速度或理解力提升。产品效果仍需通过阅读时间、即时理解和延迟回忆对照验证。
