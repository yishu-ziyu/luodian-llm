# 落点 · 原页高亮 0.1

Chrome Manifest V3 原型。用户主动点击工具栏图标或按 `Alt/Option + ,` 后，插件只在当前网页的高置信度中文正文中加入本地高亮；再次触发会完整撤销。

## 本地命令

```bash
npm run dev:extension
npm run verify:extension
npm run verify:release
```

构建产物位于 `.output/chrome-mv3`。

`verify:release` 是发布门槛：扩展回归、类型检查、MV3 重建、图标入包和 Landing Page 真实性检查必须同时通过。算法或视觉改进只有在重新加载该构建产物并完成真实 Chrome 复验后，才算进入插件版本。

## 0.1 验收标准

- 构建产物为 Manifest V3。
- 权限严格为 `activeTab`、`scripting`、`contextMenus`，没有持久站点权限。
- 没有静态 content script；只有用户主动触发后才注入当前标签页。
- 正文产生高亮，导航、页脚、按钮和代码块不产生高亮。
- 标题不高亮；高亮使用完整词语且互不相连；典型中文段落覆盖率保持在参考级的 25%–50%。
- 高亮视觉是覆盖完整字框、按 `1em` 逐字重复的柔和笔刷光斑，默认峰值透明度约 35%；不使用扁平矩形或下缘色带。
- 链接、粗体、斜体、`mark` 和显著彩色文字视为页面已有强调，不重复高亮。
- “之前、部分、内容、目前”等低信息量泛词会被降权，不能只因位置合适而成为落点。
- 高亮不改变页面纯文本、链接地址和原 URL。
- 第二次触发后插件节点全部移除，页面 HTML 恢复。
- 动态插入的新正文会被处理，插件自己的 DOM 变化不会造成循环。
- 构建产物不包含远程接口地址，用户路径无网络依赖。
- 真实浏览器中正文布局开启前后偏移不超过 1px，处理耗时低于 300ms。

Service Worker 仅记录开关结果、落点数量、耗时和错误信息；不记录正文或页面 URL。

前八项由 `npm run verify:extension` 自动检查；最后一项必须在加载构建产物的真实 Chromium 中验收。
