## 失败/坑

- LLM 在低频词密集段（如 B7「步行穿过老巷子…」）会越过 charLength；clipHighlightSpans 静默处理。
- **`splitIntoParagraphs` 只在 `\n{2,}`（双换行）分段，单 `\n` 被合并**——用户从编辑器粘贴单换行文章时整段会被当作一段，绕过 batching（Agent B 第一次跑就踩了，第二次 `\n\n` 修好）。**这是真产品风险**。
- M3 thinking 模式 60% 概率触发，retry 3 次后基本收敛；`clipHighlightSpans` 是兜底。
- WebSearch/WebFetch 走 Claude Code 不可达 → 走 exa-web-search MCP fallback（已写进 CLAUDE.md）。
- 11 天前 (6/2) 的 server cwd 错配问题依然存在（`process.cwd() === '/'` 导致 `web-mvp/.env.local` 不加载），解决方式仍是 `cd 项目根 && node web-mvp/server.mjs`。

## 产品层发现（重要）

- **TillGlance nlphl API 对英文返回 `{"0":[]}`**：12/12 篇英文全部 baseline 为空。已写进 memory `reference_tillglance_api_english_empty.md`。
- 任何用 TillGlance API 做 ground truth 的评测系统，**对英文自动失效**。
- 这意味着 web-mvp 的英文路径要么换 ground truth（自己 LLM-as-judge），要么直接走 mock 兜底 + 不声称对齐 tillglance。
